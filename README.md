# THE FIN 물건분석

더핀부동산중개법인이 분석한 법원경매 물건 원고를 **주소만 알면 볼 수 있게** 공개하는 정적 사이트입니다.

- 각 글은 네이버 모바일 화면 그대로 보이도록 만들었습니다(스마트에디터 ONE으로 재현 가능한 요소만 사용).
- 모든 페이지에 `noindex`가 걸려 있습니다 — 같은 글을 네이버 블로그에 발행할 때 중복 문서가 되지 않게 하기 위함입니다.
- 원고 생성·발행은 `thefin-auction-report/scripts/blog_publish.py`가 담당하며, 발행 전에
  형식 게이트·개인정보 검사·이미지 실재 확인을 통과해야 합니다.
